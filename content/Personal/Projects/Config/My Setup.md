The sum of configuring all my [[Dotfiles]]
My terminal-based dev environment for macOS.
# Core Components:
### Terminal Environment 
- terminal emulator: **[[ghostty]]**
- shell: **zsh** + **[[starship]]**
- multiplexer: **[[tmux]]**
- editor: **[[neovim]]**
### Desktop Environment
- window manager: **[[yabai]]**
- hotkey daemon: **[[skhd]]**
