Ghostty is a terminal emulator that differentiates itself by being fast, feature-rich and native. It's the actual application window where my terminal runs. 

I don't really have a preference for terminal emulators, I just used ghostty because I was watching someone's YouTube video and thought it looked good. So far so good. It also allowed me to set a custom background with no problem so points for that I guess.
