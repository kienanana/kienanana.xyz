**chercher: to search**

- infinitif: without subject, non-[[Conjugation|conjugated]]
- ER verb (like s’appeler)
    - e
    - es
    - e
    - ons
    - ez
    - ent

| je          | cherch | e   |
| ----------- | ------ | --- |
| tu          | cherch | es  |
| il / elle   | cherch | e   |
| nous        | cherch | ons |
| vous        | cherch | ez  |
| ils / elles | cherch | ent |

![image.png](image%204.png)

| **[[Definite and Indefinite Articles\|specific / unique]]** | **not specific / specify quantity** |
| --------------------- | ----------------------------------- |
| le                    | un                                  |
| la                    | une                                 |
| les                   | des                                 |
| l’                    |                                     |
- take note:
    - c’est: singular
    - ce sont: plural

- **[[LES ARTICLES LES POSSESSIFS|possessifs]]:**
    - in english: related to owner gender and number
    - in french: related to following noun

|           | **masculin** | **feminin** | **pluriel** |
| --------- | ------------ | ----------- | ----------- |
| je        | mon          | ma          | mes         |
| te        | ton          | ta          | tes         |
| il / elle | son          | sa          | ses         |
| nous      | notre        | notre       | nos         |
| vous      | votre        | votre       | vos         |
|           | leur         | leur        | leurs       |
