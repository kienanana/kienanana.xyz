## –eur → –euse
(masculine: –eur → feminine: –euse)
- un **chanteur** / une **chanteuse**
- un **nageur** / une **nageuse**

## –eur → –rice
(masculine: –eur → feminine: –rice)
- un **acteur** / une **actrice**

## –ier → –ière
(masculine: –ier → feminine: –ière)
- un **pâtissier** / une **pâtissière**

## Add –e (Double Consonant Pattern)
- un **chef** / une **cheffe**

## Same Form (Masculine = Feminine)
(no spelling change)
- un / une **styliste**
- un / une **journaliste**
