## ⭐ **RULES FOR COUNTRIES:**
- feminine, ends with e: la
- masculine: le
- plural (ends with s): les
	- OVERRIDES VOWEL
- begins with vowel: l’

### –ien / –ienne
(masculine: –ien → feminine: –ienne)
- **le Canada** → canadien / canadienne
- **la Guinée** → guinéen / guinéenne
- **le Mali** → malien / malienne
- **l’Algérie** → algérien / algérienne
- **le Vietnam** → vietnamien / vietnamienne
- **la Norvège** → norvégien / norvégienne
- **Singapour** → singapourien / singapourienne
- **l’Inde** → indien / indienne

### –ais / –aise
(masculine: –ais → feminine: –aise)
- **la France** → français / française
- **le Sénégal** → sénégalais / sénégalaise
- **le Japon** → japonais / japonaise

### –ois / –oise
(masculine: –ois → feminine: –oise)
- **le Luxembourg** → luxembourgeois / luxembourgeoise
- **les Seychelles** → seychellois / seychelloise
- **la Suède** → suédois / suédoise

### Same Form (Masculine = Feminine)
(no spelling change)
- **la Belgique** → belge
- **la Suisse** → suisse
