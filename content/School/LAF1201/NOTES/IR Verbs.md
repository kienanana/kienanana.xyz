# -IR Verbs
- [[Infinitives|infinitif]]: without subject, non-[[Conjugation|conjugated]]
	- eg. finir, choisir, réussir, grandir, rougir

| pronoun     | ending |
| ----------- | ------ |
| je          | is     |
| tu          | is     |
| il / elle   | it     |
| nous        | issons |
| vous        | issez  |
| ils / elles | issent |

⚠️ Many **-IR verbs add -iss-** in the **nous / vous / ils** forms.
Examples:
- je finis
- tu choisis
- il réussit
- nous finissons
- vous choisissez
- ils réussissent
    
## Example verb: FINIR (to finish)

| Pronoun     | FINIR     |
| ----------- | --------- |
| je          | finis     |
| tu          | finis     |
| il / elle   | finit     |
| nous        | finissons |
| vous        | finissez  |
| ils / elles | finissent |
- eg. nous finissons le travail
    

Some **-IR verbs are [[Irregular Verbs|irregular]]** and **do not follow these endings**.
Examples:
- venir
- partir
- dormir
- sortir

These usually have **different stems instead of the -iss pattern**.
