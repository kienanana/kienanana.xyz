Irregular verbs do not follow standard -er, -ir, or -re [[Conjugation]] pattern, often changing stems entirely in different tenses.

![[Screenshot 2026-03-06 at 1.45.17 AM.png]]

# ÊTRE (to be)  
## Conjugation  

| Pronoun     | ÊTRE   |
| -- | --- |
| je          | suis   |
| tu          | es     |
| il / elle   | est    |
| nous        | sommes |
| vous        | êtes   |
| ils / elles | sont   |
  
## Uses of ÊTRE: 
#### 1. Nationality  
- Je suis français.  
- Elle est norvégienne.  
- Ils sont japonais.  
#### 2. Profession (NO article)  
- Il est chanteur.  
- Elle est journaliste.  
- Nous sommes étudiants.  
#### 3. Adjectives  
- Je suis fatigué.  
- Elle est triste.  
- Ils sont contents.  
#### 4. Location  
- Nous sommes dans un café.  
- Je suis à la maison.


# AVOIR (to have)  
## Conjugation  
  
| Pronoun     | AVOIR |
| -- | -- |
| j’          | ai    |
| tu          | as    |
| il / elle   | a     |
| nous        | avons |
| vous        | avez  |
| ils / elles | ont   |
  
## Uses of AVOIR  
#### 1. Age  (IMPORTANT !!!!!!!!!!!!!)

- J’ai faim. (hungry)

- J’ai chaud. (hot)  
- J’ai froid. (cold)  
#### 3. Possession  
- J’ai un livre.  
- Elle a des lunettes.


# FAIRE (to do / to make)
## Conjugation

| Pronoun     | FAIRE   |
| -- | - |
| je          | fais    |
| tu          | fais    |
| il / elle   | fait    |
| nous        | faisons |
| vous        | faites  |
| ils / elles | font    |

⚠️ Irregular stem in **nous** (fais → faisons)  
⚠️ ending is silent in _fais_, _fait_, _font_

### Je fais...
- de la danse
- de l'aérobic 
- de le -> du tennis 
- de les -> des exercises de yoga 

## Uses of FAIRE
### 1. Talking about Activities / Sports
Unlike English, French often uses **faire + activity**.
- Je fais du sport.
- Tu fais du basket.
- Elle fait de la danse.
- Nous faisons de la musique.

🔎 Structure:
- **du** (de + le) → masculine nouns
- **de la** → feminine nouns
- **de l’** → vowel

Examples:
- Il fait du football.
- Elle fait de la natation.
- Je fais de l’escalade.

### 2. Weather Expressions
French uses **il fait** for many weather conditions.
- Il fait chaud.
- Il fait froid.
- Il fait beau.
- Il fait mauvais.

### 3. Expressions with FAIRE
Very common idiomatic expressions:
- faire attention → to pay attention
- faire les devoirs → to do homework
- faire un gâteau → to make a cake
- faire la cuisine → to cook

Examples:
- Je fais mes devoirs.
- Elle fait un gâteau.


# ALLER (to go)
## Conjugation

| Pronoun             | ALLER  |
| ------------------- | ------ |
| je                  | vais   |
| tu                  | vas    |
| il / elle / on (we) | va     |
| nous                | allons |
| vous                | allez  |
| ils / elles         | vont   |
### Je vais...
- à la maison 
- à l'hopital
- à le -> au cinéma
- à les -> aux toilettes

## Uses of ALLER
### 1. Talking About Where You Go
Structure:
- **aller + à + place**
Examples:
- Je vais à l’école.
- Tu vas au café. (à + le → au)
- Elle va à la bibliothèque.
- Nous allons aux États-Unis. (à + les → aux)

### 2. Near Future (Futur Proche)
Structure:
- **aller + infinitive**
This expresses something that is going to happen soon.
Examples:
- Je vais étudier.
- Nous allons manger.
- Il va regarder un film.
- Elles vont partir.

### 3. Asking How Someone Is (Common Expression)
- Comment ça va ?
- Ça va bien.
- Ça va comme ci, comme ça.
- Ça ne va pas.


# VENIR (to come)
## Conjugation

| Pronoun        | VENIR                        |
| -------------- | ---------------------------- |
| je             | viens                        |
| tu             | viens                        |
| il / elle / on | vient                        |
| nous           | venons                       |
| vous           | venez                        |
| ils / elles    | viennent (vienn, ent silent) |
⚠️ Stem changes:
- je/tu/il/elle/on → **vien-**
- nous / vous → **ven-**
- ils / elles → **vienn-**
## Structure: Venir de ...

## Uses of VENIR
### 1. Saying Where You Come From
Structure:
- **venir de + place**
Examples:
- Je viens de Singapour.
- Elle vient de France.
- Nous venons du Canada. (de + le → du)
- Ils viennent des États-Unis. (de + les → des)

### 2. Recent Past (Passé Récent)
Structure:
- **venir de + infinitive**
This expresses something that just happened.
Examples:
- Je viens de finir.
- Elle vient de partir.
- Nous venons de manger.
- Ils viennent d’arriver.

## Structure: Venir de ...
- Used to say **where someone comes from**.
## Rules

| Structure           | Use                     | Example                                  |
| ------------------- | ----------------------- | ---------------------------------------- |
| **de**              | before feminine country | Je viens **de France**                   |
| **de + le = du**    | masculine country       | Je viens **du Japon**                    |
| **de + la = de la** | feminine noun           | Je viens **de la bibliothèque / maison** |
| **de + les = des**  | plural country          | Je viens **des États-Unis**              |
| **d’**              | before vowel            | Je viens **d’Italie**                    |


# VOULOIR (to want)
## Conjugation (Présent)

| Pronoun        | VOULOIR |
| -------------- | ------- |
| je             | veux    |
| tu             | veux    |
| il / elle / on | veut    |
| nous           | voulons |
| vous           | voulez  |
| ils / elles    | veulent |
### ⚠️ Notes
- Stem changes: **veu- → voul- → veul-** ⭐⭐⭐
- je / tu have same form: **veux**
- ils / elles → **veulent** (silent -ent)
- **on = same form as il/elle → veut**

## Structure
### 1️⃣ vouloir + noun
- Je veux un café.
- Nous voulons un livre.
### 2️⃣ vouloir + infinitive
- Je veux aller au cinéma.
- Nous voulons manger.

Used in: tu veux venir ? (do you want to come ?)


# S’APPELER (to be called / to call oneself)
⚠️ **Reflexive verb** — uses [[Reflexive Pronouns]] (me, te, se, nous, vous, se)
## Conjugation

| Pronoun     | Reflexive | S’APPELER |
| ----------- | --------- | --------- |
| je          | me (m’)   | appelle   |
| tu          | te (t’)   | appelles  |
| il / elle   | se (s’)   | appelle   |
| nous        | nous      | appelons  |
| vous        | vous      | appelez   |
| ils / elles | se (s’)   | appellent |
⚠️ **Stem change:**
- _appeler → appelle / appelles / appellent_ (double **l**)
- **nous appelons** keeps the original stem
⚠️ **Elision** before vowels:
- je **m’appelle**
- tu **t’appelles**
- il **s’appelle**

## Uses of S’APPELER
### 1. Asking Someone’s Name
- Comment **tu t’appelles** ?
- Comment **vous vous appelez** ?
Formal vs informal:
- **tu** → friends / classmates
- **vous** → strangers / professors
### 2. Saying Your Name
- Je **m’appelle** Kienan.
- Elle **s’appelle** Marie.
- Ils **s’appellent** Pierre et Lucas.
### 3. Introducing Someone
- Voici mon ami. Il **s’appelle** Paul.
- Voici ma sœur. Elle **s’appelle** Camille.



# PARTIR (to leave / to depart)
⚠️ Irregular **-IR verb**
## Conjugation

| Pronoun     | PARTIR  |
| ----------- | ------- |
| je          | pars    |
| tu          | pars    |
| il / elle   | part    |
| nous        | partons |
| vous        | partez  |
| ils / elles | partent |
## Uses of PARTIR
#### 1. Leaving a Place
- Je pars maintenant.
- Il part du café.
- Nous partons de la maison.
#### 2. Saying When Someone Leaves
- Je pars à huit heures.
- Elle part demain.
#### 3. Saying Where Someone Is Going
Structure: **partir pour / partir à**
- Je pars **pour Paris**.
- Nous partons **à Montréal**.

Example sentences:
- Je pars du bureau.
- Elle part pour la France.
- Nous partons à six heures.



# CONNAÎTRE (to know / to be familiar with)
⚠️ Irregular **-RE verb**
## Conjugation

| Pronoun        | CONNAÎTRE   |
| -------------- | ----------- |
| je             | connais     |
| tu             | connais     |
| il / elle / on | connaît     |
| nous           | connaissons |
| vous           | connaissez  |
| ils / elles    | connaissent |
⚠️ Stem change:
- **connaît** keeps the **accent (î)** in the **il / elle** form
- **nous connaissons** adds **-iss-**
## Uses of CONNAÎTRE
#### 1. Knowing a Person
- Je connais Marie.
- Elle connaît le professeur.
#### 2. Being Familiar with a Place
- Je connais ce restaurant.
- Nous connaissons ce café.
#### 3. Knowing Something by Experience
- Il connaît bien Paris.

Example sentences:
- Je connais ce restaurant.
- Elle connaît ton ami.
- Nous connaissons ce quartier.

⚠️ Useful distinction you might want to add later in your notes (teachers love this):

| Verb          | Meaning                              |
| ------------- | ------------------------------------ |
| **connaître** | to know **people / places / things** |
| **savoir**    | to know **facts / skills**           |

Example:
- Je **connais** Marie.
- Je **sais** parler français.

# DEVOIR (to have to / must)
⚠️ Irregular [[IR Verbs|IR]] verb
## Conjugation

| Pronoun     | DEVOIR  |
| ----------- | ------- |
| je          | dois    |
| tu          | dois    |
| il / elle   | doit    |
| nous        | devons  |
| vous        | devez   |
| ils / elles | doivent |
⚠️ Stem changes:
- **doi-** → je, tu
- **doi- / doit** → il / elle
- **dev-** → nous, vous
- **doiv-** → ils / elles
## Uses of DEVOIR
#### 1. Obligation (must / have to)
- Je dois étudier.
- Elle doit travailler.
#### 2. Advice / recommendation
- Tu dois manger plus.
- Vous devez partir tôt.
#### 3. Probability (should / must be)
- Il doit être chez lui.
- Elle doit avoir faim.

Example sentences:
- Je dois finir mes devoirs.
- Nous devons aller à l’université.
- Ils doivent prendre le bus.
