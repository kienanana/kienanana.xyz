# Habiter (to live)
## Structure: Habiter à ...
- Used with **cities, towns, and some locations**.
## Rules

| Structure         | Use                                             | Example                               |
| ----------------- | ----------------------------------------------- | ------------------------------------- |
| **à**             | before city                                     | J’habite **à Paris**                  |
| **à + le = au**   | masculine country                               | J’habite **au Canada**                |
| **à + la = à la** | feminine country                                | J’habite **à la Jamaïque**            |
| **à + les = aux** | plural country                                  | J’habite **aux États-Unis**           |
| **en**            | feminine country OR country starting with vowel | J’habite **en France**, **en Italie** |

⚠️ General rule:

- Cities → *à*
- Feminine countries → *en*
- Masculine countries → *au*
- Plural countries → *aux*
