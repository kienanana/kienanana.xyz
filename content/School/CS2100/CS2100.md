# Self-Study Plan

|       🧪 | [**Introduction to QtSPIM**](https://www.youtube.com/results?search_query=%22An+Introduction+to+QtSPIM%22+twdr)             | Do **Lab 3: Exploring QtSpim** and preferably Lab 4 afterwards.                                                                           |
|    **7** | [**ISA + Datapath**](https://www.youtube.com/watch?v=sl2bnX3It2c)                                                           | Finish **Lec 10: ISA**, then begin **Lec 11: Processor Datapath**. Do Tut 4 afterwards.                                                   |
|    **8** | [**Datapath Part 2**](https://www.youtube.com/watch?v=DIeCV-_67sY)                                                          | **Lec 11.** Draw the datapath yourself and trace `add`, `lw`, `sw`, `beq`, etc.                                                           |

|        → | **Tutorial 5: MIPS Datapath & Control**                                                                                     | Use the current official tutorial questions + answers. This is one of the most important tutorials.                                       |
|       📚 | **Checkpoint 1**                                                                                                            | Assignment 1 + a past midterm. At this point you should be comfortable with C, MIPS, ISA and processor datapath/control.                  |
|   **10** | [**Recitation 7: Boolean Algebra, K-Maps, Simplification & Circuit Analysis**](https://www.youtube.com/watch?v=s2xmTJ6mmAI) | Use alongside **Lec 13 Boolean Algebra → Lec 14 Logic Circuits → Lec 15 Simplification**.                                                 |
|        → | [**Tutorial 6 Recording**](https://www.youtube.com/watch?v=K2MImJLAUL8)                                                     | Attempt **Tut 6: Boolean Algebra, Logic Gates & Simplification** before watching.                                                         |
| Optional | **Lec 16: Quine–McCluskey**                                                                                                 | Official slides only. **Non-examinable / own reading** in the current syllabus.                                                           |
|   **11** | [**Recitation 7: Circuit Analysis**](https://www.youtube.com/watch?v=s2xmTJ6mmAI)                                           | Now use the latter circuit-analysis material alongside **Lec 17: Combinational Circuits**.                                                |
|        → | **Tutorial 7: Combinational Circuits**                                                                                      | Attempt the [official current Tut 7 questions](https://www.comp.nus.edu.sg/~cs2100/3_ca/tutorials.html) and check answers afterwards.     |
|   **12** | **Lec 18: MSI Components**                                                                                                  | ⚠️ No dedicated MSI lecture video identifiable in the playlist. Use official Lec 18 slides as the main resource.                          |
|        → | [**CS2100 Tutorial 8**](https://www.youtube.com/watch?v=nNipt96BNAQ)                                                        | Do the current **Tut 8: MSI Components** questions first.                                                                                 |
|       🧪 | **Logic / Logisim work**                                                                                                    | Do Labs 6–9 selectively. Prioritise understanding combinational logic and multiplexers.                                                   |
|       📚 | **Checkpoint 2**                                                                                                            | Assignment 2.                                                                                                                             |
|   **13** | [**Recitation 9**](https://www.youtube.com/watch?v=zyx2XAuWeIo)                                                             | Use with **Lec 19: Sequential Logic Parts 1–3**. Then do Tut 9: Sequential Circuits.                                                      |
|   **14** | [**Recitation 11: MIPS Pipelining**](https://www.youtube.com/watch?v=qYKXPXOKrlI)                                           | Use with **Lec 20: Pipelining I** and **Lec 21: Pipelining II**. Pay particular attention to data/control hazards, stalls and forwarding. |
|        → | [**Tutorial 10: Pipelining**](https://www.youtube.com/watch?v=3QgG1yuI8bU)                                                  | Attempt the official pipeline questions and blank pipeline chart first.                                                                   |
|   **15** | [**Recitation 12: Cache Design**](https://www.youtube.com/watch?v=u_CXOVzM8YI)                                              | Use with **Lec 22: Direct-Mapped Cache** + **Lec 23: Fully/Set-Associative Cache**.                                                       |
|        → | [**Tutorial 11: Cache**](https://www.youtube.com/watch?v=iktwdIedzDQ)                                                       | Finish the official Tut 11 questions, then check the recording/answers.                                                                   |
|       📚 | **Checkpoint 3**                                                                                                            | Assignment 3.                                                                                                                             |
| Optional | **Lec 24: Performance**                                                                                                     | Official slides. Current syllabus labels it reading-only/non-examinable.                                                                  |
|       🏁 | **Final consolidation**                                                                                                     | Past finals, especially MIPS/datapath, digital logic, pipelining and cache.                                                               |
