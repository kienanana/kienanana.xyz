# Situation 2: Comparer des logements

## Vocab Bank
### Les logements
- un logement: accommodation / a home 
	- des logements: housing / homes
- un appartement: flat / apartment
- un loft: loft apartment
- un studio: studio flat / studio apartment
- une maison: house
- un chalet: chalet / mountain cabin
- un logement meublé: furnished accommodation
- un logement non meublé: unfurnished accommodation
- meublé(e): furnished
- non meublé(e): unfurnished
- lumineux (lumineuse): bright / full of natural light
- à la campagne: in the countryside
- à la montagne: in the mountains
- en ville: in the city
- un voisin (une voisine): neighbour
- comparer des logements: to compare homes / accommodation
- rêver de: to dream of

### Les pièces
- un salon: living room / sitting room
- un séjour: living room / main living area
- une cuisine: kitchen
- une salle à manger: dining room
- une salle de bains: bathroom
- une chambre: bedroom
- un placard: closet / cupboard
- un couloir: hallway / corridor
- une terrasse: terrace
- un balcon: balcony
- les toilettes (WC, f. pl.): toilet / restroom
- un garage: garage
- une cave: cellar / basement room
- un grenier: attic
- une entrée: entrance / entrance hall
- un jardin: garden
- une cour: courtyard / yard

### Les éléments de la maison
- une fenêtre: window
- une cheminée: chimney / fireplace
- la porte: the door
- un escalier: staircase / stairs

### Les étages
- le rez-de-chaussée (RDC): ground floor
- le premier étage: first floor above the ground floor

> French floor numbering starts with **le rez-de-chaussée** at street level. In Singapore, this is usually **Level 1 / the first storey**.

| France             | Singapore               |
| ------------------ | ----------------------- |
| le rez-de-chaussée | Level 1 / first storey  |
| le premier étage   | Level 2 / second storey |
| le deuxième étage  | Level 3 / third storey  |

> **Une cave** is below the ground floor; **le sous-sol** means the basement / underground level. **Les toilettes** refers to the toilet facilities; **une salle de bains** is a bathroom for bathing, which may be separate from the toilet.

## Comparer les adjectifs et les noms

| Comparaison | Avec un adjectif       | Avec un nom (quantité) |
| ----------- | ---------------------- | ---------------------- |
| Plus        | plus + adjectif + que  | plus de + nom + que    |
| Égalité     | aussi + adjectif + que | autant de + nom + que  |
| Moins       | moins + adjectif + que | moins de + nom + que   |
**Aussi** goes with an **adjective**; **autant de** goes with a **noun**. Use **d'** before a vowel or silent h: *autant d'espace*.

| Comparaison | Exemple avec un adjectif                       | Exemple avec un nom                                |
| ----------- | ---------------------------------------------- | -------------------------------------------------- |
| Plus        | Cette maison est **plus grande que** l'autre.  | Cette maison a **plus de chambres que** l'autre.   |
| Égalité     | Cette maison est **aussi grande que** l'autre. | Cette maison a **autant de chambres que** l'autre. |
| Moins       | Cette maison est **moins grande que** l'autre. | Cette maison a **moins de chambres que** l'autre.  |
Conjugate the verb for the subject. The adjective agrees with the noun it describes: *Cette maison est aussi grande que l'autre.*
