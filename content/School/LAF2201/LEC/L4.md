### Rappel
- le passé composé avec "être"
	- être present + participe passé
	- je suis **allé**(e)
	- tu es **allé**(e)
	- il est **allé**
	- elle est **allée**
	- nous sommes **allé**(e)**s**
		- second e if all féminin
	- vous êtes **allé**(e)(s)
		- vous can be used to address someone udk
	- ils sont **allés**
	- elles sont **allées**
