# Unite 7: LAB
## Vocab Bank:
### La famille: family
- le neveu : nephew
- la nièce : niece
- le benjamin / la benjamine : youngest child / sibling in a family
- le jumeau / la jumelle : twin
	- des jumelles (f. pl.) : female twins; also binoculars
	- j'ai une sœur jumelle : I have a twin sister
	- j'ai une jumelle : I have a twin sister
- l'arrière-grand-père (m.) : great-grandfather
- l'arrière-grand-mère (f.) : great-grandmother
- les arrière-grands-parents (m. pl.) : great-grandparents
- l'arrière-petit-fils (m.) : great-grandson
- l'arrière-petite-fille (f.) : great-granddaughter
- les arrière-petits-enfants (m. pl.) : great-grandchildren
