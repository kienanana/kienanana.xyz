- paresseux / paresseuse : lazy

- nerveux / nerveuse : nervous

## Les qualités et les défauts -Comparison
These are classroom contrasts, not all exact antonyms: *original* and *vulgaire*, for example, describe different traits; *bavard* contrasts more directly with *silencieux* than with *timide*.

## Le féminin des noms et des adjectifs
The screenshot also gives **créatif → créative** (-if → -ive) and **doux → douce**. Learn **roux → rousse** separately; not every -oux adjective becomes -ouce.

|                        |         | **Masculin**              |         | *Féminin*                        |
| ---------------------- | ------- | ------------------------- | ------- | -------------------------------- |
| Féminin = masculin + e | -t, -d… | un client / un Allemand   | + e     | une cliente / une Allemande      |
|                        | -t, -d… | intelligent / bavard      | + e     | intelligente / bavarde           |
|                        | -é      | désordonné                | + e     | désordonnée                      |
| Féminin = masculin     | -e      | un élève / sympathique    | =       | une élève / sympathique          |
|                        | —       | un professeur*            | = / + e | un professeur* / une professeure |
|                        | —       | un pompier* / un médecin* | =       | un pompier* / un médecin*        |
| Féminin ≠ masculin     | -s      | gros                      | -sse    | grosse                           |
|                        | -x      | roux                      | -sse    | rousse                           |
|                        | -er     | un boulanger              | -ère    | une boulangère                   |
|                        | -eur    | un vendeur                | -euse   | une vendeuse                     |
|                        | -eur    | un acteur                 | -trice  | une actrice                      |
|                        | -ien    | un informaticien          | -ienne  | une informaticienne              |
|                        | —       | un copain**               | —       | une copine**                     |
|                        | —       | un garçon**               | —       | une fille**                      |
Notes:
- \* Some profession names are not (yet) used in the feminine form.
- \*\* Some feminine nouns are completely different words from their masculine equivalents.
