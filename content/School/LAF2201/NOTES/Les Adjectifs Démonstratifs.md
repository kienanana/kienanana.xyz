# Les adjectifs démonstratifs
- **Go before a noun** to indicate “this / that / these / those”.
- Agree with the **gender and number of the noun**:

| Noun | Form | Example |
| --- | --- | --- |
| Masculine singular, before a consonant or aspirated h | ce | ce bracelet |
| Masculine singular, before a vowel or silent h | cet | cet objet, cet homme |
| Feminine singular | cette | cette montre, cette amie |
| Plural, either gender | ces | ces bracelets, ces montres |

- **Cet is still masculine**; a feminine noun keeps **cette**, even before a vowel: *cet ami / cette amie*.
- To specify distance or contrast, add **-ci / -là after the noun**: *cette montre-ci / cette montre-là* (this watch / that watch).

## Adjectif vs pronom démonstratif

See [[Les Pronoms Démonstratifs]] for the pronoun forms.

| Adjectif: accompanies the noun | Pronom: replaces the noun |
| ------------------------------ | ------------------------- |
| ce bracelet                    | celui-ci / celui-là       |
| cet objet                      | celui-ci / celui-là       |
| cette montre                   | celle-ci / celle-là       |
| ces bracelets                  | ceux-ci / ceux-là         |
| ces montres                    | celles-ci / celles-là     |

- *Je préfère **cette montre**.* → I prefer **this watch**.
- *Je préfère **celle-ci**.* → I prefer **this one**.
