# Masculin → féminin

An adjective agrees with the **noun it describes**. Start with the masculine singular form and use the patterns below to form the feminine singular.

> **un étudiant organisé → une étudiante organisée**  
> An organised student: both the person noun and its adjective change.

Examples below come mainly from [[LAF2201 Vocab Bank]]. The sections follow the ending-by-ending approach of [CliffsNotes: Changing Masculine to Singular Feminine](https://www.cliffsnotes.com/study-guides/french/french-i/french-i-adjectives/changing-masculine-to-singular-feminine).

## 1. General rule: add -e

| Masculine   | Feminine     | English        |
| ----------- | ------------ | -------------- |
| grand       | grande       | tall / big     |
| petit       | petite       | small / short  |
| intelligent | intelligente | intelligent    |
| confiant    | confiante    | confident      |
| bavard      | bavarde      | talkative      |
| brun        | brune        | dark-haired    |
| blond       | blonde       | blond          |
| joli        | jolie        | pretty         |
| poli        | polie        | polite         |
| connu       | connue       | known / famous |
| bleu        | bleue        | blue           |
| original    | originale    | original       |

Adding **-e** can make a previously silent final consonant audible: *petit → petite*. It does not always change pronunciation: *joli → jolie* sounds the same.

## 2. Already ends in -e: unchanged

| Masculine | Feminine | English |
| --- | --- | --- |
| jeune | jeune | young |
| mince | mince | slim |
| timide | timide | shy |
| autonome | autonome | independent |
| honnête | honnête | honest |
| dynamique | dynamique | energetic |
| sympathique | sympathique | nice / friendly |
| rouge | rouge | red |

> Il est **timide**. → Elle est **timide**.

## 3. Ends in -é: add -e → -ée

An accented **é** is different from a final unaccented **e**. Keep the accent and add **e**; pronunciation stays the same.

| Masculine | Feminine | English |
| --- | --- | --- |
| organisé | organisée | organised |
| désorganisé | désorganisée | disorganised |
| motivé | motivée | motivated |
| âgé | âgée | elderly / aged |
| bouclé | bouclée | curly |
| foncé | foncée | dark |
| serré | serrée | tight |

## 4. Ends in -eux: -eux → -euse

| Masculine | Feminine | English |
| --- | --- | --- |
| heureux | heureuse | happy |
| joyeux | joyeuse | joyful |
| curieux | curieuse | curious |
| généreux | généreuse | generous |
| paresseux | paresseuse | lazy |
| nerveux | nerveuse | nervous |
| ennuyeux | ennuyeuse | boring |
| rigoureux | rigoureuse | thorough / meticulous |

**Exception to memorise:** *vieux → vieille*.

## 5. Ends in -f: -f → -ve

| Masculine | Feminine | English |
| --- | --- | --- |
| créatif | créative | creative |
| sportif | sportive | sporty / athletic |
| positif | positive | positive |
| neuf | neuve | brand-new / unused |

> un pull **neuf** → une robe **neuve**

## 6. Ends in -er: -er → -ère

| Masculine | Feminine | English |
| --- | --- | --- |
| dernier | dernière | last |
| premier | première | first |
| particulier | particulière | particular / private |

> le mois **dernier** → l'année **dernière**

**Spelling:** use a grave accent (**è**): *dernière*, not *derniére*.

## 7. Double the final consonant + -e

| Ending / pattern | Masculine | Feminine | English |
| --- | --- | --- | --- |
| -en → -enne | moyen | moyenne | average |
| -ien → -ienne | ancien | ancienne | old / previous |
| -on → -onne | bon | bonne | good |
| -on → -onne | mignon | mignonne | cute |
| -el → -elle | exceptionnel | exceptionnelle | exceptional |
| -el → -elle | essentiel | essentielle | essential |
| -eil → -eille | pareil | pareille | same / alike |
| Some -l endings | nul | nulle | rubbish / lousy |
| Some -s endings | gros | grosse | big / bulky / fat |
| Some -s endings | épais | épaisse | thick |

**Do not double every final consonant.** Compare these pairs from the bank:

- *bon → bonne*, but *brun → brune* and *fin → fine*.
- *gros → grosse*, but *gris → grise*, *précis → précise* and *assis → assise*.
- *nul → nulle*, but *génial → géniale* and *principal → principale*.

## 8. Ends in -eur: learn the pair

The bank includes *travailleur → travailleuse* (hardworking) and *menteur → menteuse* (dishonest / a liar). **-eur does not have one universal feminine ending**, especially in job titles; see the person-noun table below.

## 9. Irregular forms to remember ⭐

| Masculine | Feminine | English              | What to notice       |
| --------- | -------- | -------------------- | -------------------- |
| beau      | belle    | beautiful / handsome | -eau → -elle         |
| nouveau   | nouvelle | new                  | -eau → -elle         |
| vieux     | vieille  | old                  | Learn the whole form |
| doux      | douce    | gentle / soft        | -x → -ce             |
| roux      | rousse   | red-haired / ginger  | -x → -sse            |
| blanc     | blanche  | white                | Add -he              |
| long      | longue   | long                 | Add -ue              |
| gentil    | gentille | kind / nice          | Double l + e         |
| malin     | maligne  | clever / cunning     | -in → -igne          |

### Beau, nouveau, vieux: special masculine forms

Before a **masculine singular noun beginning with a vowel or silent h**, use **bel, nouvel, vieil**.

| Usual masculine  | Before a vowel / silent h | Feminine          |
| ---------------- | ------------------------- | ----------------- |
| un beau garçon   | un bel homme              | une belle femme   |
| un nouveau livre | un nouvel album           | une nouvelle robe |
| un vieux manteau | un vieil ami              | une vieille veste |

These special forms remain **masculine**. After the noun, use the usual form: *L'album est nouveau.*

## 10. People and job nouns from the vocab bank

Some person nouns follow similar patterns. Change the article too: **un → une**, **le → la**.

| Pattern        | Masculine     | Feminine        | English            |
| -------------- | ------------- | --------------- | ------------------ |
| Add -e         | un étudiant   | une étudiante   | student            |
| -é → -ée       | un employé    | une employée    | employee           |
| -ien → -ienne  | un musicien   | une musicienne  | musician           |
| -ien → -ienne  | un comédien   | une comédienne  | actor / actress    |
| -en → -enne    | un lycéen     | une lycéenne    | high-school pupil  |
| -er → -ère     | un banquier   | une banquière   | banker             |
| -eur → -euse   | un danseur    | une danseuse    | dancer             |
| -teur → -teuse | un recruteur  | une recruteuse  | recruiter          |
| -teur → -trice | un directeur  | une directrice  | director / manager |
| -eur → -eure   | un ingénieur  | une ingénieure  | engineer           |
| -eur → -eure   | un professeur | une professeure | teacher            |
| Same word      | un artiste    | une artiste     | artist             |
| Same word      | un collègue   | une collègue    | colleague          |
| Same word      | un élève      | une élève       | school pupil       |

Memorise job titles as pairs: *recruteur → recruteuse* and *directeur → directrice* have the same masculine ending but different feminine endings.

## Common traps
- **Agree with the noun being described:** *Elle a les cheveux longs.* The adjective describes masculine plural **cheveux**, even though the person is female. Compare *Elle a une longue frange* (a long fringe).
- **Object nouns have their own gender:** *un pantalon* and *une robe* are different nouns, not masculine/feminine versions of one word. Learn each noun with its article.
- **Some colour words stay unchanged:** *une veste marron*, *une robe orange*, *une chemise crème*. Compound colours also stay unchanged: *une chemise bleu clair*. See [[LAF2201 Vocab Bank#Colours|Colours]].
- **Not every unchanged adjective ends in -e:** informal *sympa* stays *sympa*: *Il est sympa. Elle est sympa.*
- **Past participles have separate agreement rules:** *Elle est arrivée*, but *Elle a travaillé*. See [[Passé Composé#Accord du participe passé|participle agreement]].
