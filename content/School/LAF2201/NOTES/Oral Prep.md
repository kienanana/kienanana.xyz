## 1. Buying clothing

**Prompt:** Vous achetez un vêtement dans un magasin. Posez des questions au vendeur : taille, essayage, opinion.

**Roles:** A = customer, B = salesperson. Use **vous**.

**Textbook variation, printed p. 134:** buy a new T-shirt, ask about colour, price and size, choose one and pay. Practise the same script with *un tee-shirt* in place of *un pull*, and make the payment explicit.

### Essential vocabulary and phrases

| French | English |
| --- | --- |
| un vêtement ; un pantalon ; un pull ; une chemise ; une robe | an item of clothing; trousers; sweater; shirt; dress |
| la taille ; la couleur ; le prix | size; colour; price |
| une cabine d'essayage | a fitting room |
| essayer | to try on |
| trop grand / petit ; trop cher | too big / small; too expensive |
| **Vous l'avez en taille M / en bleu ?** | Do you have it in size M / in blue? |
| **Est-ce que je peux l'essayer ?** | Can I try it on? |
| **Qu'est-ce que vous en pensez ?** | What do you think of it? |
| **Ça me va ? / Ça vous va bien.** | Does it suit / fit me? / It suits / fits you well. |
| **Combien ça coûte ? / Je le prends.** | How much is it? / I'll take it. |

### Extra vocabulary used in the longer script

| French | English |
| --- | --- |
| épais / épaisse ; serré(e) | thick; tight |
| les manches ; être à l’aise | sleeves; to feel comfortable |
| un sèche-linge ; un ticket | a tumble dryer; a receipt |

### Skeleton

A: travel context + clothing need → B: size, colour and two options → A/B: compare prices and warmth → A: try on + ask opinion → B: suggest smaller size → A: explain a previous purchase + choose → A/B: washing instructions, payment and closing.

**Optional follow-up if your timed rehearsal is short:** A: « Est-ce que je peux l’échanger si la taille ne convient pas ? » B: « Oui, avec le ticket, dans les quinze jours. »

### Sample pair dialogue

**Length:** 294 spoken French words, both roles combined. Aim for about 3½ minutes with natural pauses and reactions. Time your pair aloud.

**A :** Bonjour, je cherche un pull pour l'hiver. Je vais partir en France le mois prochain et je n'ai pas de vêtements assez chauds.

**B :** Bonjour ! Bien sûr. Vous préférez quelle couleur et quelle taille faites-vous normalement ?

**A :** Je fais du M. J'aime bien le bleu, mais je voudrais quelque chose que je peux porter avec un pantalon noir.

**B :** Regardez ces deux modèles. Celui-ci est bleu foncé et celui-là est gris. Le bleu est plus chaud que le gris.

**A :** Je préfère le bleu. Combien coûte ce modèle ? Je suis étudiant, alors mon budget est de quarante euros.

**B :** Il coûte trente-cinq euros. Le gris coûte trente euros, mais il est moins épais.

**A :** D'accord. Est-ce que je peux essayer le bleu en taille M, s'il vous plaît ?

**B :** Oui, bien sûr. Les cabines d'essayage sont au fond, à droite. Prenez votre temps.

**A :** Merci. Je viens de l'essayer, mais les manches sont un peu longues. Qu'est-ce que vous en pensez ?

**B :** Vous avez raison. Il est un peu grand. Je vais vous apporter la taille S pour comparer.

**A :** Oui, merci. Le pull que j'ai acheté l'année dernière était aussi trop grand. Je ne le porte presque jamais.

**B :** Voilà la taille S. Essayez celui-ci. À mon avis, cette taille va mieux vous aller.

**A :** C'est beaucoup mieux ! Il n'est pas trop serré ? Je voudrais être à l'aise.

**B :** Non, il vous va très bien. Vous pouvez bouger les bras facilement ?

**A :** Oui, sans problème. Je le prends. Comment est-ce que je dois le laver ?

**B :** Lavez-le en machine à trente degrés et ne le mettez pas au sèche-linge.

**A :** Très bien. Est-ce que je peux payer par carte ?

**B :** Oui. Cela fait trente-cinq euros. Voici votre ticket. Merci et bon voyage !

**A :** Merci pour vos conseils. Bonne journée !

**Course connections:** [[School/LAF2201/TUT/TUT 2|TUT 2]]: trying on clothes, fit and washing instructions; [[School/LAF2201/LEC/L9|L9]]: clothing role-play, budget and payment.

**Grammar in this dialogue:** **Comparison**: *plus chaud que le gris*; **Relative que**: *quelque chose que je peux porter*; **Recent past**: *je viens de l’essayer*; **Passé composé + imparfait**: *j’ai acheté / était trop grand*; **COD pronoun**: *je ne le porte presque jamais*; **Imperative**: *Lavez-le / ne le mettez pas*.

**If the answer changes:** « Nous n'avons plus cette taille. » → « Vous avez un autre modèle ? »

**Watch:** *Je le prends* for **un pull**; *je la prends* for **une robe**; *je les prends* for plural items. Clothes use *taille*; shoes use *pointure*.

## 2. Seeing an exhibition

**Prompt:** Vous voulez voir une exposition. Votre ami(e) a déjà vu cette exposition. Vous lui posez des questions sur l'exposition.

**Roles:** A = interested friend, B = friend who visited. Use **tu**.

### Essential vocabulary and phrases

| French | English |
| --- | --- |
| une exposition ; un musée | an exhibition; a museum |
| un tableau ; une photo ; un artiste | a painting; a photo; an artist |
| l'entrée ; un billet ; un tarif étudiant | admission; a ticket; a student rate |
| les horaires ; ouvert / fermé | opening hours; open / closed |
| **Tu as aimé l'exposition ?** | Did you like the exhibition? |
| **Qu'est-ce que tu as préféré ?** | What did you like most? |
| **Qu'est-ce qu'on peut voir ?** | What can we see? |
| **Combien coûte l'entrée ?** | How much is admission? |
| **C'est ouvert jusqu'à quelle heure ?** | Until what time is it open? |
| **Combien de temps dure la visite ?** | How long does the visit last? |

### Extra vocabulary used in the longer script

| French | English |
| --- | --- |
| autrefois ; un habitant | in the past; an inhabitant |
| reconnaître ; les mêmes | to recognise; the same ones |
| surtout ; certainement | especially; certainly |

### Skeleton

A: ask about exhibition → B: past visit + opinion → A/B: favourite photos and childhood memories → compare past and present → ask about crowds, transport, price and hours → A: plan a visit with brother → agree to discuss it afterwards.

**Optional follow-up if your timed rehearsal is short:** A: « Est-ce qu’on peut prendre des photos dans le musée ? » B: « Oui, mais sans flash. J’ai pris quelques photos avec mon téléphone. »

### Sample pair dialogue

**Length:** 324 spoken French words, both roles combined. Aim for about 3½ minutes with natural pauses and reactions. Time your pair aloud.

**A :** Salut ! Je voudrais voir l'exposition de photos au musée. Tu l'as déjà vue ?

**B :** Oui, j'y suis allé samedi avec ma sœur. Nous avons passé presque deux heures au musée. C'était vraiment intéressant.

**A :** Ah bon ? Qu'est-ce qu'on peut voir exactement ? Je ne connais pas bien cette exposition.

**B :** Il y a des photos de Paris autrefois et aujourd'hui. On peut comparer les rues, les magasins et les vêtements des habitants.

**A :** Ça a l'air sympa ! Qu'est-ce que tu as préféré ?

**B :** Les photos des vieux quartiers. Quand j'étais petit, j'habitais à Paris, alors j'ai reconnu plusieurs endroits.

**A :** Tu trouves que Paris a beaucoup changé ?

**B :** Oui ! Sur les anciennes photos, il y avait moins de voitures. Mais certains bâtiments sont toujours les mêmes.

**A :** J'aime bien les expositions qui racontent la vie quotidienne. Est-ce qu'il y avait beaucoup de monde ?

**B :** Oui, surtout l'après-midi. Je te conseille d'y aller le matin, parce que c'est plus calme.

**A :** D'accord. Le musée est où exactement ? Est-ce que je peux y aller en métro ?

**B :** Oui, il est près de la gare, à côté de la bibliothèque. Prends la ligne deux et descends à la station République.

**A :** Merci. Combien coûte l'entrée ? Il y a un tarif étudiant ?

**B :** Oui, c'est cinq euros pour les étudiants et dix euros pour les autres visiteurs. N'oublie pas ta carte d'étudiant !

**A :** Et quels sont les horaires ? Je suis libre dimanche matin.

**B :** Le musée ouvre à dix heures et ferme à dix-huit heures. Il est fermé le lundi.

**A :** Parfait. Je vais proposer à mon frère d'y aller avec moi. Il adore prendre des photos.

**B :** Bonne idée ! Il va certainement aimer les photos de nuit. Ce sont celles que ma sœur a préférées.

**A :** Merci pour toutes ces informations. Je vais réserver nos billets ce soir.

**B :** Avec plaisir ! Tu vas me raconter ta visite après ?

**A :** Bien sûr ! On peut en parler lundi après le cours.

**Course connections:** [[School/LAF2201/LEC/L3|L3]]: describing a past atmosphere; [[School/LAF2201/TUT/TUT 5|TUT 5]]: exhibition context; [[School/LAF2201/LEC/L10|L10]]: opinions and relative pronouns.

**Grammar in this dialogue:** **Passé composé**: *j’y suis allé / j’ai reconnu*; **Imparfait**: *j’étais petit / il y avait*; **Comparison**: *moins de voitures / plus calme*; **Relative qui**: *les expositions qui racontent*; **Demonstrative pronoun**: *celles que ma sœur a préférées*; **Near future**: *je vais réserver*.

**If the answer changes:** « Je ne connais pas les horaires. » → « D'accord, je vais regarder sur le site du musée. »

**Watch:** past visit = *j'ai aimé / j'ai vu / c'était*; practical facts = *c'est / il y a / ça coûte*; your plan = *je vais y aller*. A female speaker writes *j'y suis allée*; the pronunciation is the same.

## 3. Job interview at a job dating event

**Prompt:** Vous passez un entretien d'embauche dans un job dating. Présentez-vous.

**Roles:** A = candidate, B = recruiter. Use **vous**. Introduce yourself briefly, then leave room for questions.

### Essential vocabulary and phrases

| French | English |
| --- | --- |
| un emploi / un poste ; un entretien d'embauche | a job / position; a job interview |
| un étudiant / une étudiante ; les études | a student; studies |
| l'expérience ; un stage ; un CV | experience; an internship; a CV |
| motivé(e) ; ponctuel(le) ; organisé(e) | motivated; punctual; organised |
| disponible ; travailler en équipe | available; to work in a team |
| **Je fais des études d'informatique.** | I study computing. |
| **Je cherche un emploi pour l'été.** | I am looking for a summer job. |
| **J'ai déjà travaillé dans un café.** | I have worked in a café before. |
| **Je n'ai pas encore d'expérience, mais j'apprends vite.** | I do not have experience yet, but I learn quickly. |
| **Je suis disponible de juin à août.** | I am available from June to August. |
| **Quelles sont vos qualités ?** | What are your strengths? |

### Extra vocabulary used in the longer script

| French | English |
| --- | --- |
| la restauration ; accueillir | restaurant work; to welcome |
| au début ; si nécessaire | at first; if necessary |
| une formation ; un jour de repos | training; a day off |

### Skeleton

B: welcome → A: short introduction → B: ask motivation and experience → A: describe previous work + what changed → B: ask strengths, languages and availability → A: answer + ask hours and training → B: explain next step → close.

**Optional follow-up if your timed rehearsal is short:** B: « Comment est-ce que vous allez venir au restaurant ? » A: « Je vais prendre le bus. Mon logement est à vingt minutes du restaurant. »

### Sample pair dialogue

**Length:** 316 spoken French words, both roles combined. Aim for about 3½ minutes with natural pauses and reactions. Time your pair aloud.

**B :** Bonjour, installez-vous. Nous avons quelques minutes pour faire connaissance. Pouvez-vous vous présenter ?

**A :** Bonjour, je m'appelle Kienan. Je suis étudiant à Singapour et je fais des études d'informatique. Je cherche un emploi pour l'été.

**B :** Très bien. Pourquoi voulez-vous travailler dans notre restaurant plutôt que dans une entreprise d'informatique ?

**A :** Parce que j'aime le contact avec les clients. Je voudrais aussi découvrir la vie en France et améliorer mon français.

**B :** Vous avez déjà de l'expérience dans la restauration ?

**A :** Oui, l'été dernier, j'ai travaillé dans un café pendant deux mois. J'ai accueilli les clients et j'ai préparé des boissons.

**B :** Qu'est-ce que vous avez appris pendant cette expérience ?

**A :** J'ai appris à travailler en équipe. Au début, j'étais un peu timide, mais mes collègues étaient patients et ils m'ont beaucoup aidé.

**B :** Et quelles sont vos principales qualités aujourd'hui ?

**A :** Je suis ponctuel, organisé et motivé. Quand il y a beaucoup de travail, je reste calme et je demande de l'aide si nécessaire.

**B :** C'est important ici. Nous avons souvent beaucoup de clients le soir. Vous parlez quelles langues ?

**A :** Je parle anglais et j'apprends le français depuis un an. Je comprends les questions simples, mais je dois encore pratiquer.

**B :** D'accord. Quand êtes-vous disponible ? Le poste commence au début du mois de juillet.

**A :** Je suis disponible de juillet à août. Je peux travailler le soir et le week-end. Quels sont les horaires habituels ?

**B :** Vous allez travailler cinq jours par semaine, de dix-sept heures à vingt-trois heures, avec deux jours de repos.

**A :** Cela me convient. Est-ce que vous proposez une formation pour les nouveaux employés ?

**B :** Oui. Pendant la première semaine, vous allez travailler avec un collègue qui connaît bien le restaurant.

**A :** Très bien. Voici mon CV. Est-ce que vous avez besoin d'autres documents ?

**B :** Pas pour le moment. Nous allons vous contacter la semaine prochaine. Merci d'être venu.

**A :** Merci pour votre temps. Au revoir et bonne journée !

**Course connections:** [[School/LAF2201/LEC/L5|L5]]: presenting yourself for work and personal qualities; [[School/LAF2201/TUT/TUT 4|TUT 4]]: professional profile and availability. The available activity-book answers also model a job-dating introduction.

**Grammar in this dialogue:** **Completed duration**: *j’ai travaillé… pendant deux mois*; **Imparfait**: *j’étais / étaient*; **Ongoing duration**: *j’apprends… depuis un an*; **Purpose**: *pour l’été* (purpose / intended period; compare *pour + infinitive* in topic 4); **Relative qui**: *un collègue qui connaît*; **Near future**: *vous allez travailler*.

**If the answer changes:** « Vous parlez quelles langues ? » → « Je parle anglais et un peu français. » Add only languages you actually speak.

**Watch:** say *je suis étudiant*, without *un*. Adapt *étudiante, motivée, ponctuelle, organisée* as needed. Replace the degree and availability with your details when practising.

## 4. Calling a restaurant for a summer job

**Prompt:** Vous êtes étudiant(e) et vous cherchez un job d'été en France. Téléphonez à un restaurant pour prendre rendez-vous pour un travail de serveur / serveuse.

**Roles:** A = applicant, B = restaurant manager. Use **vous**. The required outcome is an appointment for a job interview.

### Essential vocabulary and phrases

| French | English |
| --- | --- |
| un job d'été ; un serveur / une serveuse | a summer job; a waiter / waitress |
| une annonce ; le responsable / la responsable | an advertisement; the person in charge |
| un rendez-vous ; un entretien ; une adresse | an appointment; an interview; an address |
| **Allô, bonjour. Je vous appelle pour l'annonce.** | Hello. I am calling about the advertisement. |
| **Vous cherchez toujours un serveur ?** | Are you still looking for a waiter? |
| **Est-ce que je peux parler au responsable ?** | May I speak to the person in charge? |
| **Je voudrais prendre rendez-vous pour un entretien.** | I would like to arrange an interview. |
| **Est-ce que mardi à quinze heures vous convient ?** | Does Tuesday at 3 p.m. suit you? |
| **Oui, cela me convient.** | Yes, that suits me. |
| **Qu'est-ce que je dois apporter ?** | What should I bring? |

### Extra vocabulary used in the longer script

| French | English |
| --- | --- |
| concernant ; se terminer | concerning; to finish |
| recevoir quelqu’un ; c’est noté | to receive / meet someone; noted |
| un courriel ; en face de | an email; opposite |

### Skeleton

B: answer → A: advertisement + vacancy → B: ask studies, experience and availability → A: answer + ask hours → request appointment → negotiate an inconvenient time → ask address, directions and documents → repeat appointment → close.

**Optional follow-up if your timed rehearsal is short:** A: « Combien de temps dure l’entretien ? » B: « Environ vingt minutes. Nous allons parler de votre expérience et du poste. »

### Sample pair dialogue

**Length:** 319 spoken French words, both roles combined. Aim for about 3½ minutes with natural pauses and reactions. Time your pair aloud.

**B :** Restaurant Le Jardin, bonjour ! Qu'est-ce que je peux faire pour vous ?

**A :** Allô, bonjour. Je m'appelle Kienan. Je vous appelle pour votre annonce concernant un poste de serveur pour l'été.

**B :** D'accord. Vous voulez des renseignements sur le poste ?

**A :** Oui, s'il vous plaît. Je voudrais savoir si le poste est toujours disponible.

**B :** Oui, je suis la responsable. Nous cherchons encore une personne pour juillet et août. Vous êtes étudiant ?

**A :** Oui, je suis étudiant à Singapour. Je vais passer l'été en France pour travailler et pratiquer mon français.

**B :** Très bien. Vous avez déjà travaillé dans un restaurant ou dans un café ?

**A :** Oui, j'ai travaillé dans un café pendant deux mois l'été dernier. J'ai servi les clients et préparé des boissons.

**B :** C'est intéressant. Vous êtes disponible le soir et le week-end ?

**A :** Oui, sans problème. Quels sont les horaires habituels ?

**B :** Le travail commence à dix-huit heures et se termine à vingt-trois heures. Nous pouvons discuter des jours pendant l'entretien.

**A :** D'accord. Je voudrais justement prendre rendez-vous pour un entretien. Est-ce que vous êtes disponible cette semaine ?

**B :** Oui. Je peux vous recevoir mardi à quinze heures. Cela vous convient ?

**A :** Je suis désolé, j'ai un cours à cette heure-là. Est-ce que seize heures est possible ? Mon cours finit à quinze heures trente.

**B :** Oui, seize heures, c'est possible. Vous connaissez l'adresse du restaurant ?

**A :** Non, je viens d'arriver dans la ville. Vous pouvez me donner l'adresse et m'expliquer comment venir ?

**B :** Bien sûr. C'est au douze, rue Victor-Hugo, à cinq minutes à pied de la gare. Le restaurant est en face de la pharmacie.

**A :** Très bien, nous sommes tous les deux étudiants. Je voudrais réserver deux places pour quatorze heures.

**B :** Je suis désolé, il reste seulement une place à cette heure-là. Par contre, il y a encore plusieurs places à seize heures.

**A :** D'accord, nous allons prendre le bateau de seize heures. Qu'est-ce que nous pouvons faire avant le départ ?

**B :** Vous pouvez vous promener dans le quartier du Panier. Il est moins loin que la plage et il y a beaucoup de petits cafés.

**A :** Parfait ! Où est le point de départ du bateau ? Nous ne connaissons pas bien la ville.

**B :** Au Vieux-Port. Voici un plan. Le point de départ est ici, à dix minutes à pied. Arrivez quinze minutes avant.

**A :** Merci. Pour les deux billets étudiants, cela fait vingt-quatre euros, c'est bien ça ? Je peux payer par carte ?

**B :** Oui, bien sûr. Voici vos billets. N'oubliez pas vos cartes d'étudiant !

**A :** Merci pour vos conseils. Bonne journée !

**B :** Avec plaisir. Bonne promenade !

**Course connections:** Textbook printed p. 134, PDF page 150: tourist-office role-play; [[School/LAF2201/LEC/L9|L9]]: activities, preferences, weather and asking for advice.

**Grammar in this dialogue:** **Passé composé**: *nous avons visité / avons marché*; **Reason**: *parce que nous avons beaucoup marché*; **Comparison**: *moins loin que la plage*; **Relative qui**: *les étudiants qui présentent*; **Near future**: *nous allons prendre*; **Imperative**: *Arrivez / N’oubliez pas*.

**If the answer changes:** « Il n'y a plus de places à quatorze heures. » → « Alors, je prends deux places pour seize heures. »

**Watch:** distinguish *à quatorze heures* (at 2 p.m.) from *pendant une heure* (for one hour). If the prompt supplies prices, schedules or pretend money, use those details. The times and prices above are invented for practice.

## Final rehearsal

1. Read a script aloud together with a timer. Aim for about 3½ minutes for both roles combined. If you are short, use the optional follow-up; if you are over, shorten one descriptive answer or secondary question. Keep the core task intact.
2. Pick a topic at random and assign roles. Keep only its skeleton visible.
3. Include the actual task: an opinion for clothing, an introduction for the interview, an appointment for the restaurant call, and a solution or next step for the internet problem.
4. Change one detail each round: size unavailable, price too high, appointment inconvenient, or unknown opening hours.
5. Swap roles. The second partner should practise asking questions as well as answering them.
6. Check: consistent *tu / vous*, one question at a time, reactions to answers, and a natural ending. Use the repair phrases if you get stuck.

**If time is short:** prioritise *je voudrais*, *est-ce que*, *combien*, *quand*, *vous pouvez / tu peux*, *parce que*, *d'accord*, and one opening and closing for each register. Then learn the topic-specific bold phrases and practise the skeletons aloud.
