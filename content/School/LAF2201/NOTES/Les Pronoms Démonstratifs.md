# Les pronoms démonstratifs
- THIS or THAT
- **Replace a noun / noun group** already understood: “this one / that one / these ones / those ones”.
- **[[Les Adjectifs Démonstratifs|Adjectif démonstratif]] + noun**: *cette montre* → **pronom démonstratif**: *celle-ci*.
- Choose the form according to the **gender and number of the noun replaced**:

|           | Singular | Plural |
| --------- | -------- | ------ |
| Masculine | celui    | ceux   |
| Feminine  | celle    | celles |

- Add **-ci** for “this one / these ones” (nearer) or **-là** for “that one / those ones” (farther): *celui-ci, celle-là, ceux-ci, celles-là*.
- They can also **distinguish two choices**, without literal distance: *Je préfère celle-ci à celle-là.* (I prefer this one to that one.)
- Example: *Cette montre est pratique. Celle-là est moins chère.* → **celle-là** replaces *cette montre*.
- For this use, keep **-ci / -là**; the bare forms usually need a complement, e.g. *celle de Marie* (Marie's one).
