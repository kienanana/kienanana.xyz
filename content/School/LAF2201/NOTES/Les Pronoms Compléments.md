# Les pronoms compléments: le, la, l', les
These pronouns replace a **direct object (COD)** to avoid repeating it. COD stands for **complément d'objet direct**.

## Identify the direct object (COD)
Find the verb, then ask a question **after the verb**:
- **Qui ?** (whom?) for people: *Je vois le professeur.* → Je vois **qui** ? **Le professeur** is the COD. → *Je **le** vois.*
- **Quoi ?** (what?) for things: *Je prends l'appartement.* → Je prends **quoi** ? **L'appartement** is the COD. → *Je **le** prends.*

The object connects to the verb **without a preposition**. 
	If the question needs *à qui ?* or *à quoi ?*, it is an indirect object: *Je parle au professeur.* → Je parle **à qui** ? Here, *au professeur* is not a COD.

“After the verb” describes where to put **qui / quoi in the identifying question**, not where to place the object pronoun.

## Choose the pronoun

| Object replaced | Pronoun | Example |
| --- | --- | --- |
| Masculine singular | le | Je vends mon appartement. → Je **le** vends. |
| Feminine singular | la | Je loue ma maison. → Je **la** loue. |
| Plural, either gender | les | Je donne mes documents. → Je **les** donne. |
| Singular before a vowel or silent h | l' | Vous avez votre carte d'identité ? → Vous **l'**avez ? |

**Le / la** become **l'** before a vowel or silent h; **les** stays unchanged. Choose the gender and number of the object, not the subject.

## Placement
Place the pronoun **before the conjugated verb**:
- Je **le prends**.
- Je **ne le prends pas**. Negation surrounds the pronoun and verb.
- Je **l'ai** pris. In the passé composé, it goes before the auxiliary; see [[Passé Composé]] for agreement.

With a conjugated verb + infinitive, place it **before the infinitive it belongs to**: *Je vais **le louer**.*

In an affirmative command, place it **after the verb** with a hyphen: *Prends-le !* In a negative command: *Ne le prends pas !*

**Le, la, les** before a noun are articles (*la maison*); before a verb, they can be object pronouns (*je la loue*).

## Agreement in the passé composé
> not tested in this mod, but i found this interesting

With **avoir**, the **past participle agrees with the COD when the COD comes before the verb**. Object pronouns **le, la, l', les** come before the auxiliary, so use the gender and number of the noun they replace.

*Elle a mis les fleurs dans un vase.* → *Elle **les** a **mises** dans un vase.*

Here, **les** replaces **les fleurs** (feminine plural): **mis + e + s = mises**. The participle agrees with *les fleurs*, not with the subject *elle*. The auxiliary **a** stays unchanged.

| COD replaced                    | Example                            | Agreement                             |
| ------------------------------- | ---------------------------------- | ------------------------------------- |
| le bouquet (masculine singular) | Elle l'a **mis** dans un vase.     | No added ending                       |
| la fleur (feminine singular)    | Elle l'a **mise** dans un vase.    | Add -e                                |
| les bouquets (masculine plural) | Elle les a **mis** dans un vase.   | Plural -s is already present in *mis* |
| les fleurs (feminine plural)    | Elle les a **mises** dans un vase. | Add -es                               |

**Les** indicates plural but does not tell you the gender; check the noun it replaces. When the COD comes **after** the verb, there is no agreement with **avoir**: *Elle a **mis** les fleurs dans un vase.*
