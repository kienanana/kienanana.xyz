- Use a **pronom tonique after a preposition** when referring to a person: *chez, avec, pour, sans, de, à, autour de*, etc.
- They also work for **emphasis** (*Moi, je…*) and **standalone answers** (*Et toi ?*). They do not replace the subject pronoun directly: *Moi, je travaille*, not *Moi travaille*.
- **Watch out:** with verbs such as *parler à*, use an indirect object pronoun: *Je parle à Marie → Je lui parle.* But after *avec*: *Je parle avec elle.*

### Impératif
- Used for **commands, advice or requests**. Use the present-tense **tu / nous / vous** form without the subject: *Écoute ! Écoutons ! Écoutez !* Drop the **-s** of *tu* for **-er** verbs (and *aller*): *Parle ! Va !*
	- *Racontez-nous !* = **Tell us!** (*vous* form; pronoun after the verb with a hyphen). Negative: *Ne nous racontez pas !*

### Le Passé Composé:
![[Screenshot 2026-10-08 at 7.16.56 PM.png]]
> see [[Passé Composé#Accord du participe passé|Passé Composé]]

- With **être**, the past participle agrees with the subject: **+e** feminine, **+s** plural, **+es** feminine plural (*devenue, revenus, revenues*).
- Examples: *Emma est née à Paris. Elle est partie vivre à Lyon.*
- **Être** is used with the listed movement/change-of-state verbs and pronominal verbs; see the linked note for exceptions.

### Les verbes avec être au passé composé

| Le verbe  | Le verbe au passé composé |
| --------- | ------------------------- |
| aller     | je suis allé(e)           |
| venir     | je suis venu(e)           |
| entrer    | je suis entré(e)          |
| sortir    | je suis sorti(e)          |
| passer    | je suis passé(e)          |
| retourner | je suis retourné(e)       |
| monter    | je suis monté(e)          |
| descendre | je suis descendu(e)       |
| tomber    | je suis tombé(e)          |
| rester    | je suis resté(e)          |
| arriver   | je suis arrivé(e)         |
| partir    | je suis parti(e)          |
| naître    | je suis né(e)             |
| mourir    | je suis mort(e)           |
**(e)** = add **e** if the speaker is feminine. Some of these verbs take **avoir** with a direct object; see [[Passé Composé#Verbs that can also take *avoir*|Passé Composé: avoir exceptions]].
