# Unite 6 LAB 
## Vocab Bank:

### Verbes pronominaux — daily routines
- se raser : to shave
- se promener : to go for a walk
- se brosser les dents : to brush one's teeth
- se réveiller : to wake up
- se coucher : to go to bed
- se fâcher : to get angry
- se doucher : to take a shower
- se maquiller : to put on makeup
- se dépêcher : to hurry up
- se parfumer : to put on perfume
- se laver : to wash oneself
- se lever : to get up
- se peigner : to comb one's hair
- se préparer : to get ready
- être en forme : to be in good shape / to feel fit
- une journée type : a typical day
- répéter : to rehearse; to repeat
- une représentation : a performance
- minuit (m.) : midnight

### Décrire une personne — appearance
- brun / brune : dark-haired / brunette
- châtain (cheveux châtains) : chestnut-brown (hair)
- les cheveux (m. pl.) : hair
- long / longue : long
- les yeux (m. pl.) : eyes
- les yeux noirs : dark / black eyes
- les yeux marron : brown eyes (*marron* stays unchanged)
- mince : slim
- une barbe : a beard
- porter une barbe / avoir une barbe : to have a beard
- avoir l'air fatigué / fatiguée : to look tired (*elle a l'air fatiguée*)
- le nez : nose
- les cheveux raides : straight hair
- la hanche : hip

### Objets — objects
- un panier : a basket

### Travail et bien-être — work and well-being
- un ingénieur / une ingénieure : an engineer
- un employé / une employée; un salarié / une salariée : an employee; a salaried employee
- recruter : to recruit / hire
- changer de métier : to change professions
- faire attention à : to pay attention to
- le bonheur : happiness (not necessarily stronger than English “happiness”)
- le bien-être : well-being
- un / une responsable du bonheur : a chief happiness officer
- un objectif : an aim / objective
- en bonne santé : in good health / healthy
- un entretien d'embauche : a job interview
- un petit-déjeuner : breakfast
- un after-work : an after-work social gathering
- un atelier de créativité : a creativity workshop
- couramment : fluently

### Prendre rendez-vous — appointments and phone calls
- prendre rendez-vous : to make an appointment
- un agenda : a diary / planner
- l'objet de l'appel (m.) : the purpose of the call
- fixer une date : to set a date
- confirmer : to confirm
- prendre congé : to say goodbye / take one's leave
- je voudrais… : I would like…
- je pourrais… : I could…; a polite request in *Est-ce que je pourrais… ?* (“Could I…?”)
- C'est de la part de qui ? : Who's calling?
- de la part de : from / on behalf of
- Ne quittez pas ! : Please hold! (on the phone)
- une offre de stage : an internship advertisement / opportunity
- les disponibilités (f. pl.) : available times / availability
- disponible : available
- C'est noté. : Noted. / I've written that down.
- On dit mardi à 15 h ? : Shall we say Tuesday at 3 p.m.?
- Bonne journée ! : Have a good day!

### Profil professionnel — professional profile
- rédiger : to write / draft
- un profil professionnel : a professional profile
- un titre : a title / headline
- un résumé : a summary
- une rubrique : a section / category
- une carte de visite : a business card
- la situation actuelle : the current situation
- le poste recherché : the position sought
- la disponibilité : availability
- la mobilité : willingness / ability to relocate or travel for work
- être en recherche d'emploi : to be looking for a job
- diplômé / diplômée : holding a qualification / having graduated
- la relation clients : customer relations
- rigoureux / rigoureuse : thorough / meticulous
- ouvert / ouverte d'esprit : open-minded
- motivé / motivée : motivated
- intégrer une entreprise : to join a company
- maîtriser les bases : to have a command of the basics
- dès maintenant : starting now / immediately
- se déplacer : to travel / move from one place to another
- la formation en cours : ongoing education / training
- les compétences (f. pl.) : skills
- le métier souhaité : the desired profession
