# Ateliers: Exposer un problème
## Vocab Bank:
### Le téléphone portable (Mobile phone)
- un téléphone portable : a mobile phone
- un appel : a phone call
- un message : a message
- un SMS : a text message
- un forfait : a mobile phone plan
- le wi-fi : Wi-Fi
- un réseau : a network
- une appli (application) : an app (application)
- éteindre : to switch off
- allumer : to switch on
- rallumer : to switch back on
- être déchargé : to be out of battery
- recharger la batterie : to recharge the battery
