## Vocab Bank:
### La famille - family
- le grand-père : grandfather
- la grand-mère : grandmother
- le père : father
- la mère : mother
- le fils : son
- la fille : daughter
- le frère : brother
- la sœur : sister
- le beau-frère : brother-in-law
- la belle-sœur : sister-in-law
- la nièce : niece
- le neveu : nephew
- l’oncle (m.) : uncle
- la tante : aunt
- le cousin / la cousine : cousin
- les parents (m. pl.) : parents
- les grands-parents (m. pl.) : grandparents
- le petit-fils : grandson
- la petite-fille : granddaughter
- les petits-enfants (m. pl.) : grandchildren
- le mari : husband
- la femme / l’épouse : wife
- le beau-père : father-in-law / stepfather
- la belle-mère : mother-in-law / stepmother
- le demi-frère : half-brother
- la demi-sœur : half-sister

**Attention :** *les parents* means “parents”; *la famille* or *les membres de la famille* refers to family or relatives.
